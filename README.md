# Proyectitos
Aplicación web para centralizar toda la información de tus proyectos personales (links, notas, tareas) y colaborar con otros usuarios en proyectos compartidos, pudiendo asignar tareas y filtrarlas por persona.  Idea en una línea: un gestor de proyectos para cada uno, donde lo más importante es poder participar en proyectos de otros y asignar tareas
